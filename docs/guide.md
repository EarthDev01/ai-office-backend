## เริ่มต้นติดตั้ง {#start}

ผู้ช่วย AI จัดเป็น 3 ชั้น — ทำตามลำดับนี้ครั้งเดียวต่อหลังบ้านลูกค้า 1 เว็บ

<div class="tiers">
<div class="tier"><b>กลุ่ม</b><span>หัวจัดหมวด ตั้งชื่อเอง เช่น ระบบเดียวกันหลายเว็บ</span></div>
<span class="arrow" aria-hidden="true">→</span>
<div class="tier"><b>domain</b><span>หลังบ้าน 1 URL มีการตั้งค่าหน้าตาของตัวเอง</span></div>
<span class="arrow" aria-hidden="true">→</span>
<div class="tier"><b>service</b><span>แบรนด์/เว็บย่อยใน domain นั้น แชทแยกกัน</span></div>
</div>

1. **สร้างกลุ่ม** — เมนู *หลังบ้านลูกค้า* → ปุ่ม "+ สร้างกลุ่ม"
2. **เพิ่ม domain** — ในกลุ่มนั้นกด "+ เพิ่ม domain" แล้วใส่ URL ของหลังบ้าน เช่น `https://office.example.com`
   <div class="note">AI จะขึ้นเฉพาะเว็บที่ URL ตรงกับช่องนี้ · 1 domain ใส่ได้ 1 URL · <code>www.</code> กับไม่มี <code>www.</code> นับเป็นคนละ domain</div>
3. **เลือกชนิดหลังบ้าน** — ในหน้าตั้งค่า domain เลือก "ชนิดหลังบ้าน" ให้ตรงกับหลังบ้านที่จะแปะ snippet (เช่น หลังบ้าน v10x · หลังบ้าน abatech) แล้วกดบันทึก
   <div class="note">widget อ่านการล็อกอินและยิงข้อมูลตามชนิดนี้ · domain ที่สร้างก่อนมีตัวเลือกนี้ถือเป็นชนิดตั้งต้น (หลังบ้าน v10x)</div>
4. **เพิ่ม service** — ในหน้าตั้งค่า domain กด "เพิ่ม service"
   <div class="note">รหัส service ต้องตรงกับค่าที่หลังบ้านลูกค้าใช้ระบุเว็บที่แอดมินเลือกอยู่</div>
5. **แปะ snippet** — คัดลอกบรรทัด `<script>` จากหน้าตั้งค่า domain ไปแปะในโค้ดหลังบ้านครั้งเดียว
   <div class="note">snippet ชุดเดียวใช้ได้ทุก domain — deploy ไปกี่ URL ก็ได้ ไม่ต้องแก้</div>
6. **เปิด service** — กดสวิตช์ของ service ให้เป็น "เปิด" แอดมินที่ล็อกอินหลังบ้านและมีสิทธิ์ service นั้นจะเห็นปุ่ม AI ทันที

> **หน้าเว็บผู้เล่น (ทดลอง)** — ชนิด "หน้าเว็บผู้เล่น Tangtem" ใช้แบบเดียวกัน แต่ 1 domain = 1 แบรนด์: ใส่ URL หน้าเว็บผู้เล่น · เพิ่ม service **1 ตัว** (รหัสอะไรก็ได้ ใช้แยกแชท/สถิติ) · ใส่ URL API ถ้า API ไม่ได้อยู่ที่ `<URL ของ domain>/api`
> - **ผู้เล่นที่ล็อกอิน** ดูได้เฉพาะของตัวเอง: เครดิต รายการฝาก-ถอน ถอนได้หรือยัง (+ เทิร์นที่เหลือ) โปรที่รับได้ โปรที่ติดอยู่ ประวัติโบนัส แรงก์ คืนยอดเสีย คอมมิชชั่น แต้ม/เครดิตกงล้อ เช็คอิน กล่องสุ่ม โบนัสฟรี ภารกิจ แนะนำเพื่อน เกมค้าง (ขึ้นเป็นรายการในแชท ไม่ใช่การ์ด) · ผู้ช่วยกดรับรางวัลแทนไม่ได้ — ให้ปุ่มเปิดหน้านั้นไปกดเอง
> - **คนที่ยังไม่ล็อกอิน** ก็เห็นปุ่ม ถามได้ **วันละ 6 ข้อความ** ต่อเครื่อง (ล้างข้อมูลเบราว์เซอร์ = นับใหม่) · ดูข้อมูลบัญชีไม่ได้ · ครบแล้วผู้ช่วยชวนสมัคร/เข้าสู่ระบบ
> - ถามเรื่องที่มีหน้า/หน้าต่างในเว็บ (โปรโมชั่น สมัคร ฝาก ถอน ประวัติ กงล้อ ฯลฯ) ผู้ช่วยจะแนบ **ปุ่ม** ใต้คำตอบ กดแล้วแชทปิดและหน้านั้นของเว็บเปิดขึ้นมา · ปุ่มของเมนูที่แบรนด์ไม่ได้เปิดจะไม่ขึ้น
> - คำทักทาย/ชื่อผู้ช่วยตั้งที่ service เหมือนหลังบ้าน — ควรแก้คำทักทายให้พูดกับผู้เล่น (ค่าตั้งต้นพูดว่า "ผู้ช่วยหลังบ้าน")

## หลังบ้านลูกค้า <span class="perm">office.view · แก้ไขต้องมี office.edit</span> {#customers}

หน้ารวมทุกกลุ่ม domain และ service — ค้นได้ทั้งชื่อกลุ่ม URL และชื่อ service

- **สวิตช์ของ service** — ปิดแล้วปุ่ม AI หายจากเว็บนั้นทันที (ระบบถามยืนยันก่อน) เปิดกลับได้ทุกเมื่อ
- **ปุ่ม ⋯ ของกลุ่ม** — เปลี่ยนชื่อ หรือลบกลุ่ม (ลบได้เมื่อไม่มี domain เหลือในกลุ่ม)
- **ตั้งค่า domain** — URL, กลุ่ม, ชนิดหลังบ้าน, URL API หลังบ้าน (เว้นว่าง = ใช้ `<URL ของ domain>/api`), ธีม **สีของ widget** แบบไล่สี 2–4 สี (ปุ่มลอย หัวแชท ฟองข้อความของผู้ใช้ ปุ่มส่ง · มีชุดสีสำเร็จรูปให้กด · สีตัวอักษรบนสีนั้นระบบเลือกให้) · หน้าเว็บผู้เล่นเลือก **ใช้สีของเว็บ** ได้ = widget อ่านสีของแบรนด์จากหน้าเว็บเอง ไม่ต้องตั้งสี (อ่านไม่ได้ใช้สีตั้งต้นของ widget) · บนจอมือถือ กล่องแชทเปิดเต็มจอ ตำแหน่งปุ่มลอย และซ่อนปุ่มลอย
- **แบบการ์ดของแต่ละคำถาม** (ในตั้งค่า domain) — เลือกว่าการ์ดข้อมูลในแชทของคำถามนั้นแสดงแบบไหน: **ตัวเลขเด่น** (ยอดรวม/จำนวนตัวใหญ่) · **รายการ** (แถวละรายการ สถานะเป็นป้ายสี) · **ตาราง** (เทียบหลายคอลัมน์) · **รายการเดียว** (รายละเอียด 1 รายการ) · ไม่เลือก = แบบที่ระบบแนะนำ · มีผลกับคำตอบถัดไปของทุก service ใน domain นี้
- **สวิตช์ "เปิดใช้งาน domain นี้"** — สวิตช์ฉุกเฉิน ปิดแล้วทุก service ใน domain ปิดตาม
- **ตั้งค่า service** — ชื่อที่ AI ใช้แสดง รูปผู้ช่วย คำโปรยใต้ชื่อ พื้นหลังห้องแชท และคำทักทายแรก (ต้องบอกว่าเป็นระบบอัตโนมัติ) มีหน้าตัวอย่างให้ดูทางขวา
  <div class="note"><b>ปุ่มเปิดแชท</b> เป็นฟองแชท 3D ลอยมุมจอ เลือกแบบได้จากคลังรูป (ไม่เลือก = แบบแรก) ระบบย้อมสีตามสีของ widget ให้เอง · รูปผู้ช่วยและพื้นหลังกดเลือกจากคลังรูป · ตัวเลือกแรก <b>สุ่ม</b> = ระบบสุ่มจากคลังทุกครั้งที่เปิดหน้า (ค่าเริ่มต้นเมื่อไม่ได้เลือก) · พื้นหลังมีลาย "แสงมุม" ที่วาดตามสีของ widget ด้วย · มีรูป/พื้นหลัง/คำโปรย หัวแชทจะเป็นแบบไล่สีพร้อมรูปผู้ช่วยขนาดใหญ่และจุดออนไลน์กระพริบ · คลังรูปคือไฟล์ในโฟลเดอร์ <code>static/widget/assets/avatars</code> <code>backgrounds</code> และ <code>launchers</code> ของระบบ AI (เพิ่มรูปต้อง deploy ใหม่)</div>

<div class="note"><b>ในแชทของหลังบ้าน</b> — ใต้คำตอบมี <b>ปุ่มถามต่อ</b> ทุกคำถาม (เช่น ถามรายการฝากของยูส A แล้วมีปุ่ม "รายการถอนของ A") กดแล้วส่งเป็นคำถามใหม่ ไม่ต้องพิมพ์ · คำถามทั่วไป (ทักทาย ถามเมนู) ได้ปุ่มตั้งต้นของหลังบ้านนั้น · <b>ข้อมูลรายสมาชิก</b> ถามได้เกือบทุกแท็บของหน้าประวัติสมาชิก — abatech: ยอดถอนรวม สรุปรายวัน/เดือน รายการเล่น เกมค้าง เคลื่อนไหว แนะนำเพื่อน รายได้แนะนำ กิจกรรม กระเป๋า กงล้อ ยืนยันยอดฝาก กล่องสุ่ม · v10x: ยอดตลอดชีพ ยอดตามช่วง ฝาก/ถอนทุกสถานะ รายการเล่น คืนยอดเสีย/คอม แนะนำเพื่อน กิจกรรม ยอดค้างชำระ (ไม่มีข้อมูลบัญชีธนาคาร เบอร์ รหัสผ่าน) · ถามยอดฝากของยูสโดย<b>ไม่ระบุวัน</b> (หลังบ้าน abatech) = ยอดฝากสำเร็จตั้งแต่สมัคร · ยูสที่มีรายการเกิน 200 รายการ การ์ดจะบอกว่านับจาก 200 รายการล่าสุด</div>

## ภาพรวม <span class="perm">usage.view</span> {#overview}

สรุป 7 หรือ 30 วันล่าสุด — จำนวนคำถาม token ที่ใช้ ผลตรวจคำตอบ และตารางราย service · เลือกดูเฉพาะ service ได้ที่มุมขวาบน

## ประวัติแชท <span class="perm">conversation.read</span> {#history}

ค้นบทสนทนาตาม domain, service, ผู้ใช้, ผลตรวจ และช่วงวันที่ · กดแถวเพื่อดูบทสนทนาเต็ม พร้อมการ์ดข้อมูลและเครื่องมือที่ AI เรียกใช้

> การเปิดอ่านบทสนทนาถูกบันทึกไว้ในบันทึกการเข้าถึงทุกครั้ง

แอดมินหลังบ้านดูห้องของตัวเองย้อนหลัง 7 วันได้จากปุ่ม "ประวัติ" บนหัวกล่องแชท แล้วกดเปิดคุยต่อในห้องเดิม — เห็นเฉพาะห้องที่เปิดจากการล็อกอินหลังบ้านครั้งเดียวกัน (ล็อกอินใหม่แล้วห้องเก่าไม่ขึ้นที่ widget เพื่อกันคนปลอมตัวตนมาเปิดดู) · ห้องเก่ากว่านั้นดูได้จากหน้านี้เท่านั้น

## ตรวจคำตอบ <span class="perm">verification.write</span> {#review}

คิวคำตอบที่ยังไม่ได้ตรวจ เรียงจากเก่าสุด — เทียบคำตอบกับการ์ดและหน้าจอจริง แล้วกด

- **ถูก** — บันทึกทันที
- **ผิด** — เลือกประเภทที่ผิด และพิมพ์คำตอบที่ถูกต้อง (เก็บไว้เป็นชุดทดสอบ)

ตัวเลข % ถูกต้องแสดงคู่กับจำนวนที่ยังไม่ตรวจเสมอ — ตรวจน้อย % อาจยังไม่สะท้อนความจริง

## การใช้งาน token <span class="perm">usage.view</span> {#usage}

token ที่ผู้ช่วยใช้ต่อ service — นับจากตัวเลขที่ผู้ให้บริการ LLM ส่งกลับมา (คำตอบ 1 ข้อเรียก LLM 1–4 รอบ: ข้อที่ต้องดึงข้อมูลมีรอบถามว่าต้องดึงเพิ่มไหมด้วย ดึงได้สูงสุด 3 รอบ) · ส่วนบนสรุปรายเดือน ส่วนล่างสรุปรายวันพร้อมจำนวนปฏิเสธ เครื่องมือล้ม และผลตรวจ · token ของผู้ช่วย AI ในคอนโซลแยกเป็นแถว "ผู้ช่วยคอนโซล"

## ลบข้อมูลตามคำขอ <span class="perm">deletion.manage · บันทึกการเข้าถึงต้องมี accesslog.view</span> {#deletion}

ใช้เมื่อเจ้าของข้อมูลขอให้ลบ (PDPA)

1. เลือก domain แล้วระบุอย่างน้อย 1 อย่าง: service, ผู้ใช้ หรือช่วงเวลา (ลบทั้ง domain ครั้งเดียวไม่ได้)
2. พิมพ์รหัส domain เพื่อยืนยัน
3. ดูผลได้ในตารางคำขอ — ลบแล้วกู้คืนไม่ได้

แท็บ *บันทึกการเข้าถึง* บอกว่าใครเปิดอ่านบทสนทนาไหน เมื่อไร

## ผู้ใช้และสิทธิ์ <span class="perm">user.manage</span> {#admin}

- **ผู้ใช้คอนโซล** — เพิ่มผู้ใช้ กำหนดบทบาท ระงับ รีเซ็ตรหัสผ่าน หรือรีเซ็ต 2FA
- **ตั้งค่า Permissions** — ติ๊กว่าแต่ละบทบาททำอะไรได้ · แต่ละสิทธิ์บอกว่าเปิดเมนูหรือปุ่มไหน · admin มีทุกสิทธิ์เสมอ

เปลี่ยนรหัสผ่านของตัวเองได้จากเมนูชื่อผู้ใช้มุมขวาบน

## ประวัติการทำงาน <span class="perm">audit.view</span> {#activity}

ทุกการแก้ไขในคอนโซล (ใคร ทำอะไร ค่าก่อน/หลัง) รวมถึงการเข้าสู่ระบบและการถูกปฏิเสธสิทธิ์ · กรองตามผู้ใช้ หมวด การกระทำ และช่วงเวลา

## ตั้งค่าระบบ <span class="perm">ดู office.view · แก้ไขต้องมี settings.manage</span> {#settings}

มีผลกับทุก domain และ service — บันทึกแล้วใช้กับคำถามถัดไปทันที ไม่ต้อง restart

- **โมเดล AI** — เลือกผู้ให้บริการ โมเดล และระดับการคิด · กด "ทดสอบการเชื่อมต่อ" ก่อนบันทึกได้
  <div class="note">ผู้ให้บริการที่ยังไม่มี API key กดเลือกไม่ได้</div>
- **API key** <span class="perm">llm.key.manage</span> — กด "ตั้ง key" / "เปลี่ยน" / "ลบ" ที่การ์ดผู้ให้บริการ แล้วใส่รหัส 2FA จากแอป
  <div class="note">ระบบลองเรียกผู้ให้บริการด้วย key ใหม่ก่อน ใช้ไม่ได้จะไม่บันทึก (key เดิมยังใช้ต่อ) · OpenAI-compatible ต้องกรอก Base URL ในหน้าต่างเดียวกันด้วย (ใส่ให้ในการ์ดโมเดลอัตโนมัติ) · key ถูกเข้ารหัสก่อนเก็บ หน้าเว็บเห็นแค่ 4 ตัวท้าย · ลบ key ของผู้ให้บริการที่แชทใช้อยู่ไม่ได้ ต้องเปลี่ยนโมเดลก่อน · ใส่รหัส 2FA ผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที</div>
- **ผู้ช่วย AI ในคอนโซล** — สวิตช์เปิด/ปิดปุ่มผู้ช่วยมุมขวาล่างของคอนโซลสำหรับทุกคน
- **ประสิทธิภาพ** — จำนวนคนถามพร้อมกัน เวลารอ LLM ความยาวคำตอบ และจำนวนประวัติที่ส่งให้ LLM
- **ข้อความ** — ช่องทางติดต่อ support ที่ผู้ช่วยบอกเมื่อตอบไม่ได้
  <div class="note">ระบบต่อท้ายข้อความนี้ให้เองทุกครั้งที่ผู้ช่วยตอบไม่ได้หรือแอดมินขอคุยกับคน · ถามซ้ำเรื่องเดิมที่เพิ่งตอบไม่ได้ (หรือขอคุยกับคนซ้ำ) ในห้องเดียวกัน ผู้ช่วยจะไม่ถาม AI อีก แต่ตอบช่องทางนี้ทันที · ถ้าหลังบ้านชนิดนั้นตั้งข้อความของตัวเองไว้ จะใช้ของหลังบ้านก่อน</div>

> ถ้ามีคนแก้ไปก่อน ระบบจะไม่ให้บันทึกทับ — กด "โหลดค่าล่าสุด" แล้วแก้ใหม่

## ผู้ช่วย AI ในคอนโซล {#assistant}

ปุ่มมุมขวาล่างของทุกหน้า — ถามได้ทั้งวิธีใช้คอนโซล (ตอบจากคู่มือนี้) และข้อมูลในระบบ เช่น "เดือนนี้ใช้ token เท่าไหร่" "service ไหนปิดอยู่" "มีคำตอบรอตรวจกี่ข้อ"

- **อ่านอย่างเดียว** — แก้ เปิด/ปิด หรือลบอะไรให้ไม่ได้ จะบอกว่าต้องไปทำที่หน้าไหนแทน
- **เห็นตามสิทธิ์ของคนถาม** — ข้อมูลที่บทบาทของคุณเปิดไม่ได้ ผู้ช่วยก็ดึงมาตอบไม่ได้
- **ไม่อ่านเนื้อหาแชทของลูกค้า** — ดูได้ที่เมนูประวัติแชท (มีบันทึกการเข้าถึง)
- ประวัติการคุยอยู่ในหน้าเว็บเท่านั้น ไม่เก็บลงระบบ — ปิดแท็บแล้วหายไป
- ใช้โมเดลที่ตั้งไว้ในตั้งค่าระบบ · token นับแยกเป็น "ผู้ช่วยคอนโซล"
- ผู้ที่มีสิทธิ์ settings.manage เปิด/ปิดผู้ช่วยได้ในตั้งค่าระบบ

## แก้ปัญหาที่พบบ่อย {#trouble}

### ปุ่ม AI ไม่ขึ้นบนหลังบ้าน

ไล่เช็กตามลำดับ:

1. URL ของหน้าเว็บตรงกับ "URL ของ domain" ทุกตัวอักษร (รวม `https` และ `www.`)
2. domain เปิดอยู่ และไม่ได้เปิด "ซ่อนปุ่มลอย"
3. "ชนิดหลังบ้าน" ของ domain ตรงกับหลังบ้านจริง — เลือกผิดแล้ว widget จะหา token ไม่เจอ
4. หน้าที่เปิดอยู่ผูกกับเว็บใดเว็บหนึ่ง — หลังบ้าน abatech ต้องมี `?service=` ใน URL (หน้ารวมอย่าง Dashboard ที่ไม่ได้เลือกเว็บจะไม่มีปุ่ม)
5. service ที่แอดมินเลือกอยู่มีในรายการ service และเปิดอยู่
6. แอดมินมีสิทธิ์ service นั้นในหลังบ้านลูกค้า (abatech: ระดับ 10 ขึ้นไปหรือแผนก D002 เห็นทุกเว็บ · นอกนั้นต้องมีเว็บนั้นในรายชื่อเว็บของบัญชี)
7. ขอตั๋วแชทผ่าน — widget ขอตั๋วก่อนโชว์ปุ่ม ขอไม่ผ่าน (เช่น ตรวจสิทธิ์กับหลังบ้านไม่ได้ชั่วคราว) จะไม่โชว์ปุ่ม

เปิด Console ของเบราว์เซอร์ (F12) จะมีข้อความ `[ai-office]` บอกสาเหตุ

### ปุ่มใต้คำตอบกดแล้วไม่มีอะไรเกิดขึ้น (หน้าเว็บผู้เล่น)

- เมนูนั้นแบรนด์ปิดไว้ (หน้าเว็บโชว์แม่กุญแจ) — หน้าเว็บไม่เปิดให้เอง
- หน้าเว็บเปลี่ยน id ของหน้าต่าง/ปุ่ม — แจ้งทีมให้แก้ `page_actions` ใน connector ของชนิดนั้น
- ถ้าแชทขึ้น "เปิด … ไม่ได้ ลองกดเมนูที่หน้าเว็บแทน" = หน้าเว็บไม่มีตัวเปิดหน้าต่างที่ผู้ช่วยรู้จัก

### `KIND_NOT_SUPPORTED`

domain ตั้ง "ชนิดหลังบ้าน" ที่ระบบไม่มีแล้ว — เลือกชนิดใหม่ในหน้าตั้งค่า domain

### `ORIGIN_NOT_REGISTERED`

URL ของหน้าเว็บยังไม่ได้ลงทะเบียน — เพิ่มใน "URL ของ domain" หรือสร้าง domain ใหม่สำหรับ URL นั้น

### ถามแล้วขึ้น "ผู้ดูแลระบบยังตั้งค่าไม่เสร็จ" ทุกข้อความ (`LLM_NOT_CONFIGURED`)

โมเดลที่เลือกไว้ไม่มี API key — ดูป้ายสถานะในหน้าตั้งค่าระบบ แล้วตั้ง key ที่การ์ดผู้ให้บริการ หรือเลือกผู้ให้บริการที่มี key

### การ์ดผู้ให้บริการขึ้น "ถอดรหัสไม่ได้"

กุญแจหลัก (`LLM_KEY_SECRET`) ของหลังบ้าน ai ถูกเปลี่ยน — key เดิมใช้ไม่ได้แล้ว ต้องตั้ง key ใหม่

### ขึ้น "ผู้ช่วยของเว็บนี้ถูกปิดใช้งานอยู่" แล้วปุ่มหาย

service หรือ domain ถูกปิดที่คอนโซลระหว่างที่แอดมินคุยอยู่ — เปิดสวิตช์กลับ แล้วแอดมินรีเฟรชหน้า

### ขึ้น "การเชื่อมต่อกับผู้ช่วยหมดอายุ กรุณารีเฟรชหน้า"

ตั๋วแชทหมดอายุ widget ขอใบใหม่ให้เองเงียบ ๆ 1 ครั้งแล้ว แต่ยังไม่ผ่าน — ให้แอดมินรีเฟรชหน้า (ถ้ายังขึ้นอีก ให้ล็อกอินหลังบ้านใหม่)

### ผู้ช่วยตอบว่า "กำลังตอบคนอื่นอยู่"

มีคนถามพร้อมกันเกินที่ตั้งไว้ — เพิ่ม "คนถามพร้อมกันต่อ service" ในตั้งค่าระบบ

### ผู้ช่วยตอบว่า "ไม่ตอบกลับในเวลาที่กำหนด"

LLM ตอบช้ากว่าเวลารอ — กดทดสอบการเชื่อมต่อในตั้งค่าระบบ ถ้าช้าจริงให้เพิ่มเวลารอ หรือลดระดับการคิด

### ไม่เห็นปุ่มผู้ช่วยในคอนโซล

ผู้ช่วยถูกปิดอยู่ในตั้งค่าระบบ หรือโมเดลที่เลือกไว้ยังไม่มี API key — ติดต่อผู้ที่มีสิทธิ์แก้ตั้งค่าระบบ

### เมนูบางเมนูไม่เห็น

บทบาทของคุณไม่มีสิทธิ์เมนูนั้น — ติดต่อผู้ดูแลให้เพิ่มสิทธิ์ในหน้า "ตั้งค่า Permissions"
