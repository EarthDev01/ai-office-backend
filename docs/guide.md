## เริ่มต้นติดตั้ง {#start}

ผู้ช่วย AI จัดเป็น 3 ชั้น — ทำตามลำดับนี้ครั้งเดียวต่อหลังบ้านลูกค้า 1 เว็บ

<div class="tiers">
<div class="tier"><b>กลุ่ม</b><span>หัวจัดหมวด ตั้งชื่อเอง เช่น ระบบเดียวกันหลายเว็บ</span></div>
<span class="arrow" aria-hidden="true">→</span>
<div class="tier"><b>domain</b><span>หลังบ้าน 1 URL มีการตั้งค่าหน้าตาของตัวเอง</span></div>
<span class="arrow" aria-hidden="true">→</span>
<div class="tier"><b>service</b><span>แบรนด์/เว็บย่อยใน domain นั้น แชทแยกกัน</span></div>
</div>

1. **สร้างกลุ่ม** — เมนู *หลังบ้านลูกค้า* → ปุ่ม "+ สร้างกลุ่ม"
2. **เพิ่ม domain** — ในกลุ่มนั้นกด "+ เพิ่ม domain" แล้วใส่ URL ของหลังบ้าน เช่น `https://office.example.com`
   <div class="note">AI จะขึ้นเฉพาะเว็บที่ URL ตรงกับช่องนี้ · 1 domain ใส่ได้ 1 URL · <code>www.</code> กับไม่มี <code>www.</code> นับเป็นคนละ domain</div>
3. **เพิ่ม service** — ในหน้าตั้งค่า domain กด "เพิ่ม service"
   <div class="note">รหัส service ต้องตรงกับค่าที่หลังบ้านลูกค้าใช้ระบุเว็บที่แอดมินเลือกอยู่</div>
4. **แปะ snippet** — คัดลอกบรรทัด `<script>` จากหน้าตั้งค่า domain ไปแปะในโค้ดหลังบ้านครั้งเดียว
   <div class="note">snippet ชุดเดียวใช้ได้ทุก domain — deploy ไปกี่ URL ก็ได้ ไม่ต้องแก้</div>
5. **เปิด service** — กดสวิตช์ของ service ให้เป็น "เปิด" แอดมินที่ล็อกอินหลังบ้านและมีสิทธิ์ service นั้นจะเห็นปุ่ม AI ทันที

## หลังบ้านลูกค้า <span class="perm">office.view · แก้ไขต้องมี office.edit</span> {#customers}

หน้ารวมทุกกลุ่ม domain และ service — ค้นได้ทั้งชื่อกลุ่ม URL และชื่อ service

- **สวิตช์ของ service** — ปิดแล้วปุ่ม AI หายจากเว็บนั้นทันที (ระบบถามยืนยันก่อน) เปิดกลับได้ทุกเมื่อ
- **ปุ่ม ⋯ ของกลุ่ม** — เปลี่ยนชื่อ หรือลบกลุ่ม (ลบได้เมื่อไม่มี domain เหลือในกลุ่ม)
- **ตั้งค่า domain** — URL, กลุ่ม, URL API หลังบ้าน (เว้นว่าง = ใช้ `<URL ของ domain>/api`), ธีม ตำแหน่งปุ่มลอย และซ่อนปุ่มลอย
- **สวิตช์ "เปิดใช้งาน domain นี้"** — สวิตช์ฉุกเฉิน ปิดแล้วทุก service ใน domain ปิดตาม
- **ตั้งค่า service** — ชื่อที่ AI ใช้แสดง รูป และคำทักทายแรก (ต้องบอกว่าเป็นระบบอัตโนมัติ) มีหน้าตัวอย่างให้ดูทางขวา

## ภาพรวม <span class="perm">usage.view</span> {#overview}

สรุป 7 หรือ 30 วันล่าสุด — จำนวนคำถาม token ที่ใช้ ผลตรวจคำตอบ และตารางราย service · เลือกดูเฉพาะ service ได้ที่มุมขวาบน

## ประวัติแชท <span class="perm">conversation.read</span> {#history}

ค้นบทสนทนาตาม domain, service, ผู้ใช้, ผลตรวจ และช่วงวันที่ · กดแถวเพื่อดูบทสนทนาเต็ม พร้อมการ์ดข้อมูลและเครื่องมือที่ AI เรียกใช้

> การเปิดอ่านบทสนทนาถูกบันทึกไว้ในบันทึกการเข้าถึงทุกครั้ง

## ตรวจคำตอบ <span class="perm">verification.write</span> {#review}

คิวคำตอบที่ยังไม่ได้ตรวจ เรียงจากเก่าสุด — เทียบคำตอบกับการ์ดและหน้าจอจริง แล้วกด

- **ถูก** — บันทึกทันที
- **ผิด** — เลือกประเภทที่ผิด และพิมพ์คำตอบที่ถูกต้อง (เก็บไว้เป็นชุดทดสอบ)

ตัวเลข % ถูกต้องแสดงคู่กับจำนวนที่ยังไม่ตรวจเสมอ — ตรวจน้อย % อาจยังไม่สะท้อนความจริง

## การใช้งาน token <span class="perm">usage.view</span> {#usage}

token ที่ผู้ช่วยใช้ต่อ service — นับจากตัวเลขที่ผู้ให้บริการ LLM ส่งกลับมา (คำตอบ 1 ข้อเรียก LLM 1–2 รอบ) · ส่วนบนสรุปรายเดือน ส่วนล่างสรุปรายวันพร้อมจำนวนปฏิเสธ เครื่องมือล้ม และผลตรวจ · ไม่รวม token ของผู้ช่วย AI ในคอนโซล

## ลบข้อมูลตามคำขอ <span class="perm">deletion.manage · บันทึกการเข้าถึงต้องมี accesslog.view</span> {#deletion}

ใช้เมื่อเจ้าของข้อมูลขอให้ลบ (PDPA)

1. เลือก domain แล้วระบุอย่างน้อย 1 อย่าง: service, ผู้ใช้ หรือช่วงเวลา (ลบทั้ง domain ครั้งเดียวไม่ได้)
2. พิมพ์รหัส domain เพื่อยืนยัน
3. ดูผลได้ในตารางคำขอ — ลบแล้วกู้คืนไม่ได้

แท็บ *บันทึกการเข้าถึง* บอกว่าใครเปิดอ่านบทสนทนาไหน เมื่อไร

## ผู้ใช้และสิทธิ์ <span class="perm">user.manage</span> {#admin}

- **ผู้ใช้คอนโซล** — เพิ่มผู้ใช้ กำหนดบทบาท ระงับ รีเซ็ตรหัสผ่าน หรือรีเซ็ต 2FA
- **ตั้งค่า Permissions** — ติ๊กว่าแต่ละบทบาททำอะไรได้ · แต่ละสิทธิ์บอกว่าเปิดเมนูหรือปุ่มไหน · admin มีทุกสิทธิ์เสมอ

เปลี่ยนรหัสผ่านของตัวเองได้จากเมนูชื่อผู้ใช้มุมขวาบน

## ประวัติการทำงาน <span class="perm">audit.view</span> {#activity}

ทุกการแก้ไขในคอนโซล (ใคร ทำอะไร ค่าก่อน/หลัง) รวมถึงการเข้าสู่ระบบและการถูกปฏิเสธสิทธิ์ · กรองตามผู้ใช้ หมวด การกระทำ และช่วงเวลา

## ตั้งค่าระบบ <span class="perm">ดู office.view · แก้ไขต้องมี settings.manage</span> {#settings}

มีผลกับทุก domain และ service — บันทึกแล้วใช้กับคำถามถัดไปทันที ไม่ต้อง restart

- **โมเดล AI** — เลือกผู้ให้บริการ โมเดล และระดับการคิด · กด "ทดสอบการเชื่อมต่อ" ก่อนบันทึกได้
  <div class="note">ผู้ให้บริการที่ยังไม่มี API key กดเลือกไม่ได้</div>
- **API key** <span class="perm">llm.key.manage</span> — กด "ตั้ง key" / "เปลี่ยน" / "ลบ" ที่การ์ดผู้ให้บริการ แล้วใส่รหัส 2FA จากแอป
  <div class="note">ระบบลองเรียกผู้ให้บริการด้วย key ใหม่ก่อน ใช้ไม่ได้จะไม่บันทึก (key เดิมยังใช้ต่อ) · OpenAI-compatible ต้องกรอก Base URL ในหน้าต่างเดียวกันด้วย (ใส่ให้ในการ์ดโมเดลอัตโนมัติ) · key ถูกเข้ารหัสก่อนเก็บ หน้าเว็บเห็นแค่ 4 ตัวท้าย · ลบ key ของผู้ให้บริการที่แชทใช้อยู่ไม่ได้ ต้องเปลี่ยนโมเดลก่อน · ใส่รหัส 2FA ผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที</div>
- **ผู้ช่วย AI ในคอนโซล** — สวิตช์เปิด/ปิดปุ่มผู้ช่วยมุมขวาล่างของคอนโซลสำหรับทุกคน
- **ประสิทธิภาพ** — จำนวนคนถามพร้อมกัน เวลารอ LLM ความยาวคำตอบ และจำนวนประวัติที่ส่งให้ LLM
- **ข้อความ** — ช่องทางติดต่อ support ที่ผู้ช่วยบอกเมื่อตอบไม่ได้

> ถ้ามีคนแก้ไปก่อน ระบบจะไม่ให้บันทึกทับ — กด "โหลดค่าล่าสุด" แล้วแก้ใหม่

## ผู้ช่วย AI ในคอนโซล {#assistant}

ปุ่มมุมขวาล่างของทุกหน้า — ถามได้ทั้งวิธีใช้คอนโซล (ตอบจากคู่มือนี้) และข้อมูลในระบบ เช่น "เดือนนี้ใช้ token เท่าไหร่" "service ไหนปิดอยู่" "มีคำตอบรอตรวจกี่ข้อ"

- **อ่านอย่างเดียว** — แก้ เปิด/ปิด หรือลบอะไรให้ไม่ได้ จะบอกว่าต้องไปทำที่หน้าไหนแทน
- **เห็นตามสิทธิ์ของคนถาม** — ข้อมูลที่บทบาทของคุณเปิดไม่ได้ ผู้ช่วยก็ดึงมาตอบไม่ได้
- **ไม่อ่านเนื้อหาแชทของลูกค้า** — ดูได้ที่เมนูประวัติแชท (มีบันทึกการเข้าถึง)
- ประวัติการคุยอยู่ในหน้าเว็บเท่านั้น ไม่เก็บลงระบบ — ปิดแท็บแล้วหายไป
- ใช้โมเดลที่ตั้งไว้ในตั้งค่าระบบ · ใช้ token จริงทุกคำถาม (ระบบเก็บตัวเลขไว้ แต่ไม่แสดงในภาพรวมและการใช้งาน token)
- ผู้ที่มีสิทธิ์ settings.manage เปิด/ปิดผู้ช่วยได้ในตั้งค่าระบบ

## แก้ปัญหาที่พบบ่อย {#trouble}

### ปุ่ม AI ไม่ขึ้นบนหลังบ้าน

ไล่เช็กตามลำดับ:

1. URL ของหน้าเว็บตรงกับ "URL ของ domain" ทุกตัวอักษร (รวม `https` และ `www.`)
2. domain เปิดอยู่ และไม่ได้เปิด "ซ่อนปุ่มลอย"
3. service ที่แอดมินเลือกอยู่มีในรายการ service และเปิดอยู่
4. แอดมินมีสิทธิ์ service นั้นในหลังบ้านลูกค้า

เปิด Console ของเบราว์เซอร์ (F12) จะมีข้อความ `[ai-office]` บอกสาเหตุ

### `ORIGIN_NOT_REGISTERED`

URL ของหน้าเว็บยังไม่ได้ลงทะเบียน — เพิ่มใน "URL ของ domain" หรือสร้าง domain ใหม่สำหรับ URL นั้น

### ถามแล้วขึ้น error ทันทีทุกข้อความ (`LLM_NOT_CONFIGURED`)

โมเดลที่เลือกไว้ไม่มี API key — ดูป้ายสถานะในหน้าตั้งค่าระบบ แล้วตั้ง key ที่การ์ดผู้ให้บริการ หรือเลือกผู้ให้บริการที่มี key

### การ์ดผู้ให้บริการขึ้น "ถอดรหัสไม่ได้"

กุญแจหลัก (`LLM_KEY_SECRET`) ของหลังบ้าน ai ถูกเปลี่ยน — key เดิมใช้ไม่ได้แล้ว ต้องตั้ง key ใหม่

### ผู้ช่วยตอบว่า "กำลังตอบคนอื่นอยู่"

มีคนถามพร้อมกันเกินที่ตั้งไว้ — เพิ่ม "คนถามพร้อมกันต่อ service" ในตั้งค่าระบบ

### ผู้ช่วยตอบว่า "ไม่ตอบกลับในเวลาที่กำหนด"

LLM ตอบช้ากว่าเวลารอ — กดทดสอบการเชื่อมต่อในตั้งค่าระบบ ถ้าช้าจริงให้เพิ่มเวลารอ หรือลดระดับการคิด

### ไม่เห็นปุ่มผู้ช่วยในคอนโซล

ผู้ช่วยถูกปิดอยู่ในตั้งค่าระบบ หรือโมเดลที่เลือกไว้ยังไม่มี API key — ติดต่อผู้ที่มีสิทธิ์แก้ตั้งค่าระบบ

### เมนูบางเมนูไม่เห็น

บทบาทของคุณไม่มีสิทธิ์เมนูนั้น — ติดต่อผู้ดูแลให้เพิ่มสิทธิ์ในหน้า "ตั้งค่า Permissions"
